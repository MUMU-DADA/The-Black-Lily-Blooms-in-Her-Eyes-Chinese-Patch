# 中文翻译规则

## 1. 权威源文本

- 所有中文正文必须以 `source/data/scenario/ja/` 下的日文 `.ks` 文件为唯一翻译依据。
- `source/data/scenario/en/` 只允许用于核对标签、跳转、变量、角色出场顺序和英文版已有专名；不得用英文改写来代替日文翻译。
- `source/data/scenario/zh-CN/` 是中文目标文件，目录结构和日文目录一一对应。
- 翻译顺序按剧情连续性进行：`story/chapter1s1.ks` -> `chapter1s2.ks` -> `chapter1s3.ks` -> `chapter1s4.ks` -> `chapter1s5.ks` -> `chapter2s1.ks` ...，再处理 `ifStory.ks` 和 Roguelike 事件。

## 2. 文本与脚本边界

- 只翻译玩家可见的日文文本、角色名、选项、卡牌/技能/道具说明和界面文案。
- 不翻译或改动：宏名、标签名、变量名、函数名、文件名、资源路径、数值、条件表达式、JavaScript 代码和存档字段。
- `[p]`、`[r]`、`[ruby]`、`[emb]`、`[if]`、`[else]`、`[endif]`、`[jump]` 等 TyranoScript 结构必须原样保留。
- `[ruby text="..."]` 的 `text` 是注音/读法。中文正文一般不需要日文假名注音；删除注音前必须确认该标签不会影响布局或脚本解析。稳妥做法是先保留标签，仅翻译可见内容。
- 引号、括号、破折号、省略号和换行应服从中文排版，但不能改变 `[p]` 等分页位置。
- 每个修改后的 `.ks` 文件使用 UTF-8（无 BOM）保存。

## 3. 连续上下文要求

- 翻译前先通读当前章节，至少同时阅读前后各一个场景段落；不能逐句脱离上下文直译。
- 同一段连续独白要保持叙述视角、时态和情绪递进，不要把日文连接句拆成生硬短句。
- 对省略主语、暧昧指代和反复出现的意象，优先参考前后文确定含义；无法确定时在译者备注中标记，不擅自补设定。
- 每章完成后统一检查：人物称呼、时间线、地点名、战斗术语、伏笔关键词和同一事件的前后译法。

## 4. 人物口吻基线

以下是当前从日文脚本整理出的初始基线，后续应以完整剧情为准调整：

- **壱十**：男性第一人称“我”；平时自然、克制，战斗时果断；对瞳亲近但不轻浮。避免过度书面化。
- **宵星瞳**：女性；日常温柔、体贴，偶尔俏皮；解释规则时清楚耐心；紧张或担忧时语气变短。
- **例外存在（例ちゃん先輩）**：年长前辈；称呼和语气要体现亲近与阅历，不能翻成生硬的职场敬语。
- **世界、帝、战华、纱月、雷等角色**：首次出场时记录其自称、对壱十/瞳的称呼和敬体/常体，后续全章统一。
- 旁白沿用壱十的内心叙述，兼顾文学感和可读性；不要机械保留日文长句结构。

## 5. 术语与专名

- 统一维护 [`glossary.md`](glossary.md)，新增术语先登记再继续翻译。
- 人名优先采用日文汉字对应的中文读法或作品内明确称呼；不因英文版拼写而擅自改成英文名。
- `アルカナ` 统一为“阿尔卡那”；`ファミリア` 统一为“使魔”；`鈴持ち` 统一为“持铃者”；`領域` 统一为“领域”。
- 数值与战斗缩写 `HP/ATK/DEF/SPD/Lv` 保持原样，中文说明只翻译其语义。
- 技能、道具、领域名称使用中文书名号 `『』`，并在术语表中记录正式译名和首次出现位置。

## 6. 逐文件工作流程

1. 从 `source/data/scenario/ja/<path>.ks` 读取日文原文。
2. 复制同路径文件到 `source/data/scenario/zh-CN/<path>.ks`（若尚未存在）。
3. 仅替换玩家可见文本和目标语言角色名，保留所有脚本控制内容。
4. 对照日文前后文润色，使连续对白和旁白通顺。
5. 检查中文文件中的标签、跳转目标、资源路径和 `[p]` 数量没有意外变化。
6. 在 `translation/progress.md` 记录文件状态、译者备注和待确认问题。

## 7. 交付前检查

- `zh-CN` 与 `ja` 的剧情文件数量和相对路径一致。
- 中文目录中不存在未翻译的英文占位文本，也不存在乱码（如 `繧`、`縺`）。
- 所有 `[jump storage="&sf.settingLanguage + ..."]` 路由仍然可以命中 `zh-CN` 文件。
- 角色名、卡牌名、技能说明和道具说明没有混用日文/英文键名。
- 图片内嵌文字另行处理，不能把脚本文字翻译完成误认为界面完全汉化。
- 用户明确负责实机验证，因此本阶段只做静态结构检查，不声称已完成运行验证。
